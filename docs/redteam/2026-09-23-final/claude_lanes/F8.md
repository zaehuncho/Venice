### CL3-F8-007 MEDIUM: sleep and resume still latch SAFE MODE as "UI thread froze for over 6 seconds"
- **Tier:** source-confirmed; the race order is probable. CL2-P8-003 / M-35 **still open**. The rc1 resume hook only requests a licence heartbeat (`OrionAppController.cpp:5319-5335`).
- **Failure path:**
  - `guiHeartbeatMs_` and the freeze worker both use `QDateTime::currentMSecsSinceEpoch()` (`:4992-4999`, `:6453-6454`).

### CL3-F8-009 MEDIUM: the detection-unavailable latch can be starved; raw sightings reset the blind streak, even between shots
- **Tier:** source-confirmed for the rule; hypothesis for how often real idle false locks pass `genuineOverlayFrame`. Owned by Claude (engine); the reader is Astra's, report only.
- **Evidence:**
  - `OrionAppController.cpp:11731-11743`: on `genuineRawDetection` the streak goes to 0, and this runs **before** the `physicalShotEpoch == 0` idle check (`:11747-11749`).
  - The input is `rawMeterVisible` (`:2984-2995`), which is computed on every detector frame, including idle frames.
  - The trip needs 3 **consecutive** blind armed epochs (`kMeterBlindStreakTrip_ = 3`, `OrionAppController.h:2639`).
- **Failure path:** on patch day the new meter is not detected, but the 09-21 memory records about 65 idle false locks per session. Any accepted raw detection between shots, or once per 3 shots, keeps the streak below 3. The latch never trips, `detectionUnavailable_` stays false, and `meterBlindBackstopBlockReason` returns empty. The backstop keeps releasing presses on the fixed 2K27 hold table with no warning.
  - Once latched, the fix is correct: a blip does not unlatch (`:11738-11741`).
  - The latch is also in-memory, so each restart allows up to 3 more blind timer shots before it trips again.
- **Impact:** CL2-P9-001's "blind means off" is only as strong as the false-lock rate. The customer experience is the one M-13 was meant to remove: timer shots on a meter Venice cannot see.
- **Fix:** count only detections **inside an armed epoch**. Ignore the idle `genuineRawDetection` for the streak reset, or reset only on a promoted or owned lock. Consider persisting the latch until 2 owned shots are seen, even across a restart.
- **Closure test:** a QtTest that runs 3 blind armed epochs with one idle raw detection between epochs 2 and 3. Expect a trip, and expect the 4th press to give `detection_unavailable`. The negative control: an in-epoch genuine detection still resets.
