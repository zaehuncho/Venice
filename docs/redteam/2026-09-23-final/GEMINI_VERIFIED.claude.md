# Gemini review files, checked against the current tree (Claude, 2026-09-23)

Sources checked: `CUSTOMER_WALKTHROUGH.gemini.md` (CW), `ERROR_COPY_AUDIT.gemini.md` (EA), and the factual claims in `UI_INSTALLER_BRIEF.gemini.md` (UB). This was a read-only pass: no source edits, no builds, no launches. Every file:line below is the working tree as of this pass. Gemini's line numbers are often off by 1 to 8 lines. Where they were, the current line is given.

What the status labels mean:
- **REAL**: still true now, and the fix is given.
- **OK**: Gemini's claim is accurate and needs no change. Most of these are rows Gemini itself rated Good or Exemplary.
- **STALE**: the code has changed since Gemini read it.
- **WRONG**: the claim never matched the code, or the fix is aimed at the wrong place.
- **OUT OF LANE**: covers reader files (`simple_meter_reader.py`, `meter_locator_cv.py`). These are flagged only, with no edit proposed.

Copy rules applied to every fix: say "Venice", never "Orion". No sidecar, lease, epoch, pipe, Ed25519 or `ORION_*` text. Sign-in is a "one-time code", never a "license key". The only meter style is Arrow2, and the only colour is White. The price is $19.99/month with a 7-day trial.
